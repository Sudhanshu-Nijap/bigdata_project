🏛️ The 4 Core Big Data Components

⚡ Buffer
1. Apache Kafka
The Real-Time Message Highway

Why it's used: When thousands of tweets arrive in seconds, sending them directly to a database crashes it. Kafka acts as an ultra-fast shock absorber, holding tweets in partitioned queues without dropping any data.

🔥 Engine
2. Apache Spark (PySpark)
Distributed Compute & Retraining

Why it's used: Standard Python processes one tweet at a time. PySpark splits workloads across multiple CPU cores, cleaning text, predicting sentiment in micro-batches, and retraining on millions of rows in seconds.

🧠 AI / NLP
3. Dual-Feature ML Model
97.7% Accuracy (Zero Hardcoding)

Why it's used: Combines Word N-Grams (1-3) and Character N-Grams (3-5) with regularized Logistic Regression. Classifies tweets into 4 sentiments (Positive, Negative, Neutral, Irrelevant) with zero entity bias.

💾 Storage
4. Data Lakehouse
Hot MongoDB + Cold Parquet Archive

Why it's used: MongoDB (Hot Tier) serves live dashboard queries at sub-20ms. Older tweets migrate to Snappy-compressed Parquet files (Cold Tier), saving >80% disk space while enabling instant PySpark batch scans.

🔄 Step-by-Step Execution Flow

How a single tweet moves through the entire system from the internet to storage and dashboard.

1
Live Ingestion & Topic Filtering

Tweets are continuously scraped for trending keywords or hashtags (e.g., #AI, #Tech, #Crypto) and packaged into clean JSON event payloads.

2
Publishing to Kafka Topic

The producer pushes the JSON events asynchronously into the twitter_tweets Kafka topic buffer, guaranteeing zero request stalling.

3
PySpark Sanitization & NLP Prediction

PySpark Structured Streaming strips URLs, noise, and unwanted artifacts, then applies the trained Dual-Feature ML model to predict sentiment in <0.2ms.

4
Hot Storage & Live Dashboard Streaming

Enriched records are stored in MongoDB Atlas (Hot Tier) and instantly pushed to the web dashboard via Server-Sent Events (SSE) to update real-time charts and KPI counters.

5
Cold Parquet Lakehouse Tiering

The data_lakehouse.py script periodically moves older tweets into Snappy-compressed columnar .parquet files, preventing database slowdowns and saving >80% storage cost.

6
Human-in-the-Loop Feedback & Automated Retraining

Users can click to verify/correct sentiment labels on the dashboard. PySpark loads these verified samples along with the Parquet archive to retrain and hot-reload the AI model without downtime.
